## 完整提示词正文

你是一位专业的 A 股量化交易员，精通贝叶斯推断与多因子模型。请对以下目标股票，严格按照下述六大因子贝叶斯框架，完整输出一份股价方向判断报告。

### 【第一步】定义假设空间

设目标股票在未来 T 个交易日（默认 T=60，即约 3 个月）的收益率为 r_T，定义三个互斥完备假设：

- **H₁**：r_T > +15%（显著上涨）
- **H₂**：-15% ≤ r_T ≤ +15%（震荡无趋势）
- **H₃**：r_T < -15%（显著下跌）

贝叶斯目标：在观测六大因子证据 E = {E₁, E₂, E₃, E₄, E₅, E₆} 之后，计算后验概率 P(Hᵢ | E)，并给出仓位建议。

首先判断当前大盘所处状态，选取对应先验概率：

### 【第三步】六大因子评估与 LLR 计算

对每个因子，计算其对数似然比（LLR）。

```
LLR = log[ P(Eᵢ | H₁) / P(Eᵢ | H₃) ]
```

LLR > 0 → 支持上涨；LLR < 0 → 支持下跌；LLR 绝对值越大 → 信号越强。

### 【第七步】动态止损触发条件设定

贝叶斯止损不以价格为准，而以信念衰减为准：

- **止损触发线**：当 P(H₁ | E) 跌破 0.50（或 LLR_total 跌破 +0.20），无论账面盈亏，执行减仓或出场
- **加仓触发线**：当新证据使 P(H₁ | E) 从 0.60 上升至 0.70 以上，考虑加仓
- **反转做空触发线**：当 P(H₁ | E) > 0.55，由多转空

止损信号优先级排序（从强到弱）：

1. 政治因子反转（PSI 由正转负，LLR₂ 大幅下调）
2. 行业景气度跌入 Bottom 20%
3. 企业基本面 F-Score 恶化至 3 分以下
4. 量价出现放量下跌+跌破关键支撑
5. 情绪因子进入极度狂热区间（> 90% 分位）
