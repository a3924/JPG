# 数据能力路由速查

本Skill不直接绑定单一供应商。按环境中可用能力和数据层级路由。

## 路由顺序

1. 交易所、巨潮资讯、公司投资者关系官网：公告、财报、招股书、问询回复。
2. `neodata-financial-search`：自然语言金融数据、长周期财务、历史估值和宏观行业数据。
3. `westock-data`：A股行情、K线、财务、资金、技术、股东、分红、两融、公告、研报、风险事件和新股日历。
4. 通达信连接器：深度财务、多期股东、限售解禁、问财式公告/研报/新闻查询及结构化补充。
5. 公开网络搜索：行业资料、公司官网原文和前述来源未覆盖的信息。

## 典型任务映射

- 最新行情/估值：结构化行情数据，附交易状态和时间。
- 5-10年财务：长周期财务数据 + 公司年报交叉核验。
- 技术/资金/两融：`westock-data` 或通达信，标注算法和交易日。
- 机构盈利预测：结构化一致预期 + 原始券商研报。
- 行业空间/市场份额：招股书、行业协会、监管统计、同行公告。
- IPO：交易所发行文件、新股日历、上市公告书。
- 管理层和资本配置：年报、公司治理报告、股东大会、激励、回购、定增、并购公告。

## 失败与降级

- 数据源为空时写“当前数据源未覆盖”，不要用记忆补数字。
- 搜索摘要仅作线索，必须打开原文。
- 付费数据库字段无法查看时，不推测隐藏值。
- 多源冲突时记录差异并回到A级一手披露。
- 拟上市公司没有二级市场数据时，跳过技术和资金模块。

## 计算职责

数据能力负责取数，不负责证明DCF正确。将取到的关键值写入JSON，使用本Skill脚本复算基础估值和DCF；脚本输出与数据源预计算字段冲突时，先检查股本、利润和单位口径。
