# 因子库使用说明

本目录收录两份量化的因子回测报告，是同一份回测在**两个市值池**上跑出来的结果。理解它们的关系和差异，是正确给 AI 配权重的前提。

---

## 一、两份文件的关系

| 文件 | 池子 | 定位 | 内容 |
|---|---|---|---|
| `因子库_中证500.md` | 中证500 (000905.SH)，中盘股 | **母稿 / 完整版** | 41 因子明细、跨期稳定性、大类汇总、两套权重方案、相关性矩阵、待修复清单 |
| `因子库_中证2000.md` | 中证2000 (000852.SH)，小盘股 | **增量版 / 补充** | 仅中证2000 TOP10、与中证500 的对比表、小盘特征、小盘权重建议 |

> 原始回测是同一套因子、同一时间窗（2025-03-01 → 2026-07-14），只在不同市值池里跑。中证2000 原文件前半段是"小盘增量"，后半段几乎与中证500 母稿完全重复，因此整理时**只保留增量**，避免冗余。

## 二、中证500 与中证2000 的核心区别：市值

| 维度 | 中证500 | 中证2000 |
|---|---|---|
| 市值层级 | 中盘（沪深300 之外的中等市值） | 小盘（剔除中证800 后的小市值） |
| 池内股票分化 | 相对温和 | **截面分化更大** |
| 因子选股能力 | 基准 | **系统性更强** |
| 拥挤度因子 (F2/F3) | 强 | **极强**（F3 多空累计 65.9%） |
| 流动性因子 (Amihud) | 31% | **52%**（小盘流动性溢价极高） |
| 波动率因子 (Parkinson/YZ/ATR) | 强 | **全面增强** |

**一句话**：同一套因子，在中证2000（小盘）里几乎都比中证500（中盘）更有效。

## 三、给 AI 配权重的使用原则

1. **先定池子，再选权重文件**：
   - 目标股属于中盘 / 偏大盘 → 主要参考《因子库_中证500.md》的权重方案；
   - 目标股属于小盘 / 微盘 → 在母稿基础上，按《因子库_中证2000.md》的建议**上调拥挤度、波动率、流动性三类权重**。

2. **稳定性 > 收益率**：跨期稳定的因子（Deviation_From_MA200、F3_RelativeStrength、波动率类）优先，时序不稳的 Alpha101 类因子仅作分散化补充（总权重 <10%）。

3. **大类分散**：波动率、拥挤度、技术量价、估值、盈利预期、Alpha 六大类之间相关性 <0.35，合成时各大类保持 10-30% 权重即可。

4. **动态微调**：母稿提供"IC×ICIR 动态加权法"，建议每月滚动重算一次权重，适应因子有效性变化。
